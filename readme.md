## 项目概述

CarlaGUI是一个基于PyQt5开发的图形用户界面工具，用于简化CARLA自动驾驶模拟器的操作和控制。该工具提供了直观的界面，使用户能够轻松启动、连接CARLA模拟器，并进行车辆生成、控制、环境设置等操作，无需直接编写复杂的Python代码。

## 主要功能

- **CARLA模拟器管理**：启动、关闭和连接CARLA模拟器
- **地图和环境控制**：切换地图、设置天气条件
- **车辆操作**：生成、删除和控制车辆
- **视角控制**：设置观察者位置、跟随车辆
- **渲染设置**：启用/禁用渲染、2D HUD显示
- **同步模式设置**：配置模拟器的同步/异步模式

## 使用方法

1. 设置`config.ini`文件，主要是carla路径
2. 运行`start.bat`启动GUI界面
3. 使用界面上的"启动CARLA"按钮启动模拟器（已经启动跳过该步骤）
4. 点击"连接CARLA"按钮连接到模拟器(一定要做这一步)
5. 使用界面上的各种功能按钮进行操作：
   - 生成车辆
   - 切换地图
   - 设置天气
   - 控制观察者视角
   - 等等

## 配置文件

项目根目录下的`config.ini`文件用于配置CARLA路径和默认车辆生成位置：

```ini
[CarlaSettings]
;设置你的CarlaUE4.exe安装位置
carla_path = D:\CARLA0.9.15\WindowsNoEditor\CarlaUE4.exe
;默认的车辆生成位置
Spawn_x = -1930
Spawn_y = 48.25
Spawn_z = 0.3
Spawn_yaw = 0
```
